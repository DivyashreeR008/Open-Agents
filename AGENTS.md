# Agents Directory

This file is the human-readable index of all agents in Open-Agents.
Keep it in sync with `src/agents/definitions/`. Run `npm run sync:agents` after adding an agent; `npm run check:agents` fails when the table is stale.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for how to add a new agent in ~5 minutes.

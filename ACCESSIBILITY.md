# Accessibility

Open-Agents is committed to making the project useful to as many people as possible. We continue to improve keyboard access, readable presentation, focus behavior, semantic markup, and support for assistive technologies as the application evolves.

## Current status

Accessibility work is ongoing. The project does not currently claim conformance with a specific WCAG level, and this page is not a substitute for testing the application with a user's own assistive technology or browser setup.

Known limitations may include incomplete keyboard support in some interactive flows, inconsistent focus visibility in parts of the interface, and accessibility gaps in newly added features. We track and address these issues through the repository's issue tracker.

## Report a barrier

If you encounter an accessibility barrier, please [open an issue](https://github.com/DivyashreeR008/Open-Agents/issues) with:

- The page or feature where the problem occurred.
- The steps needed to reproduce it.
- The browser, operating system, and assistive technology involved, if relevant.
- The outcome you expected and what happened instead.

Please do not include personal information, API keys, or other secrets in an issue. If your report concerns a security vulnerability, follow the private reporting process in [SECURITY.md](./SECURITY.md) instead.

We welcome specific, respectful reports and will use them to prioritize improvements.

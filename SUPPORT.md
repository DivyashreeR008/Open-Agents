# Support

## Stuck on Something?

Don't worry — everyone gets stuck. We are here to help.

If you are working on a contribution and something is not making sense —
whether it is the codebase, the agent config, the system prompt, or anything else —
just drop a comment on the issue you are working on.

We check GitHub daily and will reply within **24 hours**. No question is too small.

---

## How to Ask for Help

Just comment on the issue you are working on with something like:

> "Hey, I am stuck on [this part]. Here is what I tried — [what you did]. Can you help?"

That is it. No need to be formal. Just tell us where you are stuck and we will help you move forward.

---

## What We Can Help With

- Understanding the codebase
- Writing a good system prompt for your agent
- Figuring out which input or output type to use
- Debugging why your agent is not working
- Any general question about the project

---

## Please Don't

- Open a new issue just to ask a question — comment on the existing one instead
- Share API keys or secrets in issues, PRs, or screenshots — revoke them immediately if exposed

---

## Stay Connected

If you enjoy working on Open-Agents, hit **Watch** on the repo
so you never miss a new issue, feature, or release.

The best projects are built by people who stick around. Hope to see you here for a long time. 🙌

## Security Issues

Do not report vulnerabilities in public issues or comments. Use
[private vulnerability reporting](https://github.com/DivyashreeR008/Open-Agents/security/advisories/new) and see [SECURITY.md](./SECURITY.md).
